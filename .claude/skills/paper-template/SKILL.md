# 论文模板（paper-template）

本站每篇论文解读的唯一模板。**黄金样本：`4d-reconstruct/2024-dust3r.html`**——新页照它做；本 skill 与样本冲突时以本 skill 为准，并顺手把样本同步过来。

## 0. 总验收线（先读）

读者来这一页只回答两个问题：**这篇论文怎么做？值不值得我复现 / 值不值得深入？**

- 不允许留思维盲点：怎么做、好细节在哪、坑在哪，全部显式写清
- **读者不该需要查任何外部资料**——遇到 PnP、BA 这类词，当场用一句话解释（例：PnP = 已知 3D 点和对应像点，反求相机位置）
- 符号、配对、尺寸是读者串起「正文 ↔ 图 ↔ 结果」的锚点，必须落地（细则见 §2）

## 1. 页面结构（严格照此，每篇论文都这样）

```
页首 hero（标题 + arXiv / 代码仓 / 数据量 / venue）
§0 速览卡（浅黄底便签感：--c-scan-bg #fffbe9，--c-scan-line #f0e6c3）
│  ├─ 核心思想：一段话讲清本文干了什么
│  ├─ 五条模块（标题用抽象名词，不用口语；每条 1-2 短句）：
│  │    目标：做什么、怎么做
│  │    训练：子条 输入 / 输出 / GT / Loss
│  │    推理：子条 输入 / 输出（含三块读法：深度 / 位姿 / 对应）/ 后处理
│  │    效果：子条 定性 / 定量
│  │    结论：一句话
│  ├─ 机制/结构总图（放在被引用的条目内）
│  └─ QA 档案：学习问答逐条累积（Q + 讲透后的 A；盲点原始数据不上仓库）
§1 Motivation（问题 / 别人怎么解 / 本文怎么解 / 优点效果）
§2 Architecture（总图 + 逐子模块：原理 + 代码核对细节）
§3 Loss（公式卡 + 链图 + 数据/配方表）
§4 Results（定性 + 定量指标表，标注论文表号）
§5 Conclusion（证明了什么 / 局限 / 后续方向）
页尾 footer；左侧 sticky 目录，顶部「← 返回」按钮
```

- 速览卡的五条是骨架，任何论文都不变，只换内容；§1+ 深度不设上限，但要能被速览卡锚定
- 旧页改造与新页同规：完成后 §0 是速览卡、图按 §3 规范、字按 §4 规范

## 2. 记号与公式规则

- **Loss 必须写公式（含系数）+ 逐符号解释**，放在训练条的 Loss 文字里（叙述完直接跟 `.formula` 块）。格式：公式一行 → 每个符号一行（X 是什么、X̄ 是什么、ℓ 是什么、c/C 是什么、α 是多少）
- **符号第一次出现就解释**；配对写全（预测 X¹,¹ 对 GT X̄¹,¹）；标注形状（[3,512,512] 等）
- 真值记号写法：正文 `<span class="ovl">X</span><sup>1,1</sup>`（`.ovl{text-decoration:overline}`）；SVG 里 `<tspan text-decoration="overline">X</tspan><tspan dy="-4" font-size="9">1,1</tspan>`。**禁用组合横杠字符 X̄（U+0304）**——macOS/Chrome 里横杠会偏右

## 3. 图形规范

- **三张图各司其职**：机制/结构总图一张；**训练流程图、推理流程图各一张（分开画，放各自条目内）**
- **图里只放符号，公式放图外的文字里**——靠同名符号配对
- **全链路标 shape**：输入 [3,512,512] → 中间（F¹,F² [1024,1024]、[512,512,4] 这种）→ 输出 [512,512,3] + [512,512]
- **输入输出与关键模块不省略**：两个输入画两个独立框（不合并成「图片对」）；共享模块照实画成共享的一块
- 图幅紧凑；配色沿用：输入绿（#dafbe1/#1a7f37）、模型蓝（#ddf4ff/#0969da）、输出红（#ffebe9/#cf222e）、监督黄（#fff8c5/#d4a72c）；文字类 `.svg-cn/.svg-nota/.svg-nota-b`
- 流程图放条目内；figcap 编号连续（图 0-1、0-2、0-3…）

## 4. 文字规范

- 全部表述过全局 `renhua` skill（去 AI 腔）：短句直说、因果明写、符号配对写全、写完念一遍
- 讲解顺序过全局 `jiangtou` skill（痛点先行 / 锚点类比 / 剂量控制）
- 自查五项：破折号金句、「名词 · 金句」标题、术语不解释、配对省略、只写出脑中所想的 50-60%

## 5. 索引与状态（index.html）

- **路线组与路线图同名同序**：卡片的分组标题必须与路线图上的路线名一致（前馈式重建 域：路线一「前馈几何基座」/ 路线二「前馈 3D 高斯」/ 路线三「前馈 4D 高斯」；4D重建 域：渲染式预训练 / 占用世界模型 / Gaussian 世界模型）。顺序按路线序号，由 PAPERS 数组顺序决定（路线一的条目排在前面）
- **卡片严格按时间线排（2026-10-11 用户定，全站规则）**：路线内卡片从早到晚按年份升序排（`.sort((a,b)=>a.year-b.year)`）；同年保持 PAPERS 数组顺序。出现在路线图时间轴上的论文也照时间轴先后排
- **新论文归位**：先看它在路线图里挂在哪个路线，`route` 字段填该路线名；域归属也以路线图为准（例：DUSt3R、DrivingRecon 都在「前馈式重建」域）
- **已读标记只由源码写入**：读者读完一篇后告知 Claude → Claude 在源码标记（PAPERS 条目加 `read: true`；路线图节点加 `read` 类）→ 页面只读展示（卡片绿 ✓、节点带勾绿点），访问者不能点击更改；不要实现任何前端切换
- **对话记录归档（2026-10-11 起）**：每篇论文的完整对话（用户消息 + Claude 回复正文）在会话结束前导出到该论文所在目录的 `memory/<year>-<slug>.md`（与页面同名），随页面一起提交——记录跟着仓库走，分支可删、远端永存；所有论文都按此规则

## 6. 一句话版本

结构照 DUSt3R 页；公式进文字并逐符号解释；图里只放符号、全链路标 shape、输入输出不省略；训练推理各一图；全部说人话、不留盲点——读者看完能判断值不值得复现 / 深入。
