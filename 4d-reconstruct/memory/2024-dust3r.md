## DUSt3R 之后的重要论文（截至 2026-10）

按重要性排序，前 3 篇是必看级别：

| # | 论文 | venue | 对 DUSt3R 改了什么 | 为什么重要 |
|---|------|-------|-------------------|-----------|
| 1 | **VGGT** | CVPR 2025 **最佳论文**（Oxford VGG + Meta） | ~1B 参数大 transformer，一次前向直接输出**相机 + 点图 + 深度 + 点跟踪**，最多吃几百张图 | 谱系最有影响的后续，已 2300+ 引用；确立了「前向几何基座」这个新范式 |
| 2 | **MASt3R / MASt3R-SfM** | ECCV 2024（naver，DUSt3R 原班人马） | 点图对齐到地面坐标系 + 在点图头上加 ViT 局部特征做匹配 | 官方续作；把点图变成实用的图像匹配器，带检索的全球 SfM 落地 |
| 3 | **MonST3R** | ICLR 2025 | 每个时刻各回归一张点图（不再假设静态场景） | 打开「动态场景」整条分支——和你站上驾驶世界模型主线最有共鸣的一篇 |
| 4 | **Depth Anything 3** | 2025 | 深度估计旗舰系列改用点图回归目标、任意数量输入 | 深度估计与点图回归两大阵营在此合流，747+ 引用 |
| 5 | **MapAnything** | Meta，2025-09 | 多头分解输出（点图 × 相机 × 尺度，metric），支持可选几何输入，一个模型 12+ 任务 | 「万能前向几何基座」的当前形态 |
| 6 | **Fast3R** | CVPR 2025 | N 张图并行交叉注意力一次前向 | 解决 DUSt3R 两两配对 O(N²) 的瓶颈（被 VGGT 盖过，但方向开创者） |
| 7 | 2026 波：**VGGT-Ω**（CVPR 2026）、AMB3R、LASER 等 | 2025-11~2026 | 前向重建继续刷 SOTA + 训练免对齐增强 | 一句话带过即可：赛道仍在快跑，没有单篇必读 |

## 演化逻辑（一张图看懂分叉）

```
DUSt3R (CVPR 24, 图对→点图)
 ├─ 匹配落地线   → MASt3R (ECCV 24) ────────────→ MASt3R-SfM 全球重建
 ├─ 动态场景线   → MonST3R (ICLR 25) → CUT3R / Easi3R
 ├─ 并行多视角线 → Fast3R (CVPR 25) ─┐
 └─ 统一基座线   → VGGT (CVPR 25 最佳论文) → DA3 / MapAnything (2025) → VGGT-Ω (2026)
```

`★ Insight ─────────────────────────────────────`
- 这条谱系的演化可以压缩成三个替换：**输入侧** 图对→N 张一次前向（Fast3R/VGGT 干掉全局对齐）；**输出侧** 单一点图→分解多头（相机/深度/track/metric 尺度，VGGT 和 MapAnything 的关键差异就在头怎么分）；**场景假设** 静态→动态（MonST3R）。
- VGGT 拿最佳论文的深层原因：它证明「优化式几何」（COLMAP 那套迭代 BA）可以被一个足够大的前向 transformer 在秒级替代——这是范式级断言，不只是涨点。
`─────────────────────────────────────────────────`

**网络做的不只是预测 3D 坐标——它还额外为每个像素自报了一个"我预测这个点的误差大概有多大"。** 这个自报的不确定度记作尺度 σ，C 就是它的倒数：**C ≈ 1/σ，精度**。
- C 大 = "我对这个点的预测很精密，误差范围很窄"
- C 小 = "我这块拿不准，误差范围宽"

## 这个损失式不是拍的——它是"负对数似然"的形状

假设每个像素的 3D 误差服从一个以 σ 为尺度的分布（拉普拉斯一类），把这个分布的负对数似然写出来化简，**得到的正好就是 C·ℓ − α·log C 这个形状**。两项各有精确的统计身份：

- **C·ℓ**：标准化残差——把"错得多离谱"用"该像素自己申报的尺度"去量；
- **−α·log C**："宣称自己很精确"要交的税（分布归一化项）——你声明误差范围窄，就必须付对应的代价。

所以这条损失的完整含义是：**让每个像素自报一个噪声尺度，然后按这个假设分布算数据出现的概率（负对数）。**"两项拔河""平衡点 C* = α/ℓ"都只是它的推论——**平衡点的含义就是"校准"：自报的精度必须和真实误差吻合**，只有误差小的地方才允许报高精度；谎报会被税和残差两头夹回来。

## "1 到正无穷"的物理翻译

- **上不封顶**：一个像素真能预测到零误差，它的精度就该趋于无穷——"我对这里极精确"是合法声明，没有理由设上界；
- **下界 1**：等价于"**误差尺度最多大到 1**"（场景归一化单位下）。不许声明"我的误差可以是无穷大"——因为尺度无穷大等于这个像素对训练不产生梯度，就是弃权。这就是"逼外推"的概率版；
- **为什么偏偏不是 0~1**：0~1 是"离散事件概率"的直觉（"我 87% 确定这是猫"）；这里学的是**连续误差的尺度参数**——它天然活在正数域，没有任何理由 ≤1。就像方差不需要 ≤1、方差的倒数更不需要。

## 设计动机（一句话）

不用它、只算裸的 ℓ：难像素（天空、外推区）误差大、梯度全被它们吃掉，而且网络分不清"我错了"和"这里本来就不可预测"。学了 C 之后：**学习信号自动分配给"学得动"的像素**，难像素降权但不许归零；副产品 C 本身下游还能用（图对过滤、全局对齐加权。

另外补个背景：`C·ℓ − α·log C` 这种形态是"学不确定度"的标准做法（Kendall & Gal 那一类），DUSt3R 拿来用的同时加了下界——**下界恰恰是为了让它别变成"丢弃开关"**：作者要的从来不是"过滤"，而是"分配 + 校准 + 下游可用"。

## 推理时 C 的三处实际用法

**① 挑边——这才是真正的"过滤"（会丢弃）**
N 张图两两跑完一遍，对每一对算**预测的平均置信度**，低分的图对直接扔掉——低平均置信度意味着这两张图重叠少、或者互相看不清。剩下的高分对才进入全局对齐。页面 §2.4 的原话就写着："all跑一遍用平均置信度过滤低重叠对"。注意图少的时候不筛——比如 10 帧评测就是把全部 45 对都用上。

**② 全局对齐加权——"软过滤"（不丢弃，只降话语权）**
进入对齐优化后，**每个点的对齐残差都乘上它自己的 C**：重叠区、纹理好的点（C 大）在解位姿/深度时说话更重；天空、外推区（C≈1）几乎不影响求解结果。机制上没删任何点，只是让低置信度的点"影响变小"。

**③ 建初始化骨架——按置信度排序选边**
§2.4 的 init='mst'：按置信度建最小生成树——**置信度高的图对优先当骨架边**，先逐边 PnP 把位姿摆到大致位置，再全局细调。等价于"先信最值得信的边"。

## α 参与吗？——不参与

- α = 0.2 是**训练损失里的税率**，只活在训练阶段。它的全部工作是塑造 C 通道的最终形态（C\* = α/ℓ 这个"校准好的自评"就是它调出来的）。
- **训练一结束，α 的使命就完成了**——推理时网络只输出 c → C = 1+exp(c)，直接使用；损失不存在，α 自然也不存在。
- 类比：α 是"教练定训练强度"，C 是"学员练出来的自我评估能力"——上场打球（推理）的是学员，教练不跟着上。
- 一个间接的说法是对的：**换个 α 重训，C 的整体刻度会变**（更容易的像素 C 更高或更低），所以 α"隔着一层"影响了过滤行为的松紧——但推理代码里找不到它。

## 推理时置信度到底怎么"筛"——四层，全是真码

**① 每张图的置信度怎么来：逐像素取 max（不是平均）**
`base_opt.py`：图像 i 参与的每一对里，该像素的 C **取最大值**——"哪个邻居给的把握最大就信多少"。先把两两的置信度图融合成每张图一张 C 图。

**② 像素级硬筛：一行布尔阈值，阈值 = 3**
`get_masks()` 的实现就是：`C > min_conf_thr` 保留，否则剔除——**默认 min_conf_thr = 3**（demo 滑条范围 1~20、默认 3.0）。点云导出/可视化直接按这个 mask 筛掉低置信度的点。
筛之前还有一道**降级**：`clean_pointcloud` 拿每张点云去和别的视角的深度图对账——**穿模/不一致的点 C 直接夹到 0**；开了 mask_sky 时天空的 C 也置 0。这些点随后自然被阈值清掉。

**③ 图对级打分：两张图平均置信度的乘积**
`commons.py`：`edge_conf(i,j) = mean(Cᵢ) × mean(Cⱼ)`——**注意是乘积**。这个分数用在 MST 初始化：把边按分数从高到低建**最大生成树**——**分最高的图对先当骨架**，新图沿骨架边做"置信度加权的刚体配准"（`rigid_points_registration(..., conf=...)`，每个点用自己的 C 当最小二乘的权重）。"过滤低重叠对"就是这个语义：低分边排最后、进不了骨架。

**④ 优化级加权（不是筛）：权重 = log(C)**
对齐目标的置信度变换是 `conf='log'`——每个点的对齐残差权重是 **log(C)**。这里有个很妙的细节：**log(1) = 0**——所以 C=1 的难像素在优化里的权重恰好归零。之前你担心的"下界焊在 1、没法弃权"，在推理侧完全不成问题：**log 变换把"1"映射成了"0 权重"**。
